# GKD 1.12.4（96）· 统一图标与重复审查修复

正式 Release，包含此前只部署到手机、尚未发布的 95 版统一图标改动。

## 图标
- 启动图标、圆形图标、应用详情与安装器使用同一套新图；关于页、深浅色启动画面同步替换。通知栏、前台通知、自动执行快捷磁贴及 Android 13+ 主题图标使用对应单色头像。
- 移除旧品牌矢量、动画 Logo 和黑白启动图。截图、搜索等功能按钮不是品牌标识，保持原功能图标。
- 修正自适应图标透明背景的黑底风险，使用明确的蓝色底层；彩色与单色前景统一内缩 29%。完整图片的四角位于 Android 108dp 容器中心 66dp 圆形安全区内，避免此前 20% 内缩时的裁切风险。
- 系统主题包、第三方桌面仍可自行覆盖图标；没有清除桌面数据或更改用户主题。

## 本轮代码修复
- Root 自动重连额度不再在耗尽后永久保持为零：稳定连接满 30 秒后恢复重试额度，短时崩溃循环仍最多重试两次。新增 4 项单元测试。
- 模块打包默认从 Gradle `output-metadata.json` 读取真实 APK 名称，不再使用已失效的固定文件名；拒绝逃出输出目录的元数据路径。
- 保留模板中的模块版本，不再按打包时间重写。模块版本 **20261103.4 / 2026110304**。
- 先检查 APK ZIP 结构、Manifest 和 DEX；拒绝错误哈希、无效 APK、危险的输入／输出位置及非法版本号。
- 新 ZIP 写入临时同目录文件，通过条目及内嵌 APK 哈希校验后再替换成品，避免失败时先删除旧包。
- 复核了引擎归属、动作上下文、跨用户策略、节点租约、Binder 清理、检测文件夹排除和规则迁移路径；未更改 HMA 隐藏预设或已有黑白名单。

## 验证
- 最终同一源码提交：应用 **190** 项、Selector JVM **18** 项测试通过，合计 **208** 项，0 失败／0 错误；Selector JS 生产编译通过。
- **8** 个安装脚本模拟场景通过；**10** 个打包对照场景通过，其中包含 2 个旧版行为复现。模拟安装测试不卸载真实应用。
- Android Lint **0 错误、58 条告警**：48 条为依赖／插件更新建议，其余为现有私有 API、路径、资源及风格建议。联网补齐 JS 依赖后，更新建议数量增加；没有为消除告警而无差别升级依赖。
- 真机深浅色共 **10** 项资源渲染检查通过，旧品牌资源与引用已移除。验证的是资源加载与渲染，不等同于逐个 OEM 桌面的视觉测试。
- 主动结束自己的 Root 服务并等待重连，连续 **3** 轮成功；每轮先稳定运行 32 秒，均校验新 PID 和客户端握手日志。
- 水印相机开屏 `clickNode / Verified`，动作后验证 293ms；测试后立即结束相机进程。
- 999 用户可可影视开屏 `clickNode / Verified`，动作后验证 54ms；随后真实出现的 **“朕知道了”** 公告，命中 `btn_confirm`，执行 `clickNode / Verified / WindowChanged`，验证 57ms。以上不是完整开屏耗时。
- 主用户可可影视当前为用户停用状态（enabled=3），没有擅自启用；本轮不将其计入成功用例。公告真实点击的验证范围是本次双开场景。
- APK 已安装，现有 SukiSU 模块原位同步，内嵌 APK 与发布文件相同；单一守护进程正常，999 用户没有运行第二套 GKD 引擎。HMA、设置、本地订阅和模块 config.conf 保持原样；LSPosed 开发者模式及 Hook 调试保持关闭。
- 已执行 APK 95→96→95→96 对照、源码补丁应用与回滚；相对上一正式 Release 的公开补丁也完成应用／逆向还原校验。实际模块原文件已备份，模块降级演练及整机重启不在本轮实测内。

多轮修复后，本轮复核与回归没有发现新的阻断问题；这不是对所有设备和所有运行时状态“零缺陷”的证明。实机范围为当前 Android 17 手机，不使用截图/OCR 完成匹配。
