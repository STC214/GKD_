# GKD · 可可影视与双开跳过修复 · 2026-11-03

正式 Release，versionCode **93**。APK 与 SukiSU 配套包均包含本次实现。

## 更新
- 修复自动化/无障碍服务切换后遗漏匹配唤醒的问题；前台任务改变时重新确认窗口，有界重试，不增加常驻扫描。
- 可可影视3.5.0跳过按钮宽518px，超过通用规则500px限制：保留通用限制，仅增加完全限定按钮ID与倒计时文字的兼容选择器。
- 内置“可可影视-关闭公告”规则：精确匹配公告标题及`btn_confirm`的“朕知道了”，不点击下载、链接或协议按钮。主用户与双开共用主用户GKD规则引擎。
- 首次运行时将缺失公告规则合入本地订阅；已有同键规则不覆盖、不重复。非空本地订阅的关闭状态保持，之后用户删除规则或关闭订阅，重启不会强制恢复。
- 保留现有Root/LSP双开节点桥接、批量作用域申请、检测应用文件夹默认白名单；HMA隐藏预设不需要取消。

## 实测范围
- 发布APK：主用户可可影视开屏、主用户水印相机回归、用户999可可影视双开开屏，均有`clickNode / Verified`记录。
- 正式包本轮动作后验证耗时：可可影视原版52ms、双开52ms，水印相机189ms；不是完整启动耗时。
- 164项单元测试通过，0失败/0错误。
- 验证了已有规则保持、缺失规则补入、用户删除后重启仍保持删除；临时配置随后精确还原。
- 实际执行了APK回滚与重新安装、源码补丁应用与源码回滚；未卸载应用、未清数据，保留双开和作用域。
- HMA配置、GKD设置及现有匹配白名单保持原样。无截图/OCR；测试后相机及测试应用进程已结束。

## 已知验证边界
**“朕知道了”公告在添加规则后的测试中没有自然再次出现。因此规则已内置、已加载，但真实公告的自动点击仍待下一次自然弹出时验证。** 不将规则加载或开屏跳过成功当成公告点击成功。

没有证据认定可可影视主动破坏其他应用；本次修复的是已经观察到的匹配限制与服务唤醒遗漏，不承诺解释此前所有全局失效情况。

SukiSU包的内嵌APK与实测APK字节一致；本轮未刷模块或重启验证。新安装/新双开应用仍可能需要一次LSPosed作用域批准，之后黑白名单切换不重复申请。
