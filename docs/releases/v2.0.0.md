## 主要变化

- Zygisk 全局节点桥接，常规应用默认受主用户 GKD 策略管理，不要求逐个勾选 LSPosed 作用域或双开 GKD。
- user0 与 XSpace/999 共用主用户的一套匹配引擎；GKD 白名单、检测应用文件夹及内部保护包仍控制生效范围。
- 首装初始化兼容服务查询缩进；首次 Root 授权等待与服务握手分离，并有最多 5 分钟的有界恢复。
- 修复窗口尚未挂载时静态“跳过”节点遗漏；恢复仅有限重采样，未确认前台窗口不获得点击权限。
- 默认同时包含本地公告规则与既有在线订阅快照（667/v575；973 个应用、3 个全局组）；保留后续订阅更新和已有用户设置。
- 修复定制版分发路由：源码、提交、反馈、分享及更新入口指向本项目。关闭上游普通 APK 的自动更新入口，定制版从项目发布页配套更新 APK/Root 模块；在线规则更新不受影响，上游署名和支持入口保留。

## 使用与边界

首次使用仍需用户在 Root 管理器批准 GKD 的 Root 请求；不是静默绕过授权。新默认 Root＋无障碍路线不要求 Shizuku；沿用旧自动化配置的用户仍需保留其原 Shizuku 授权。

全局 Native 安装/替换后需按宿主要求重启。支持范围为 user0/999 的常规单包 UID；系统、隔离、共享 UID 等身份不明确的进程保持拒绝。目标应用不生成可用节点或规则不匹配时不保证跳过；不回退到截图/OCR。

实际设备覆盖为 Android17 ARM64。x86_64 仅编译/结构验证；可选32位不作为本次默认发布 payload，未作实机支持承诺。

不修改 HMA 预设；默认保留已有规则、配置、白名单。Root 节点桥接及策略为本地处理。私人应用数据备份、日志和设备特定回退材料不上传 Release。

本项目基于上游 GKD；原许可证、来源和规则作者元数据保留。
