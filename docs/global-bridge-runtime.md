# 2.0 全局节点运行时与维护契约

基线：`v2.0.0`（APK2.0.0/100，Root模块2.0.0/2026110402）。[文档索引](README.md)／[源码差异指南](upstream-code-delta-guide.md)／[验证矩阵](testing/global200-release.md)。

## 组成与数据流

```text
Root管理器 + 已启用Zygisk宿主
  ├─ 模块Native：筛选受支持UID/用户与保护包，加载全局Java助手
  ├─ 目标进程助手：Activity生命周期、节点连接的短租约恢复/撤销
  └─ 主用户GKD APK（普通应用UID，唯一规则匹配引擎）
       ├─ 设置/白名单/规则/订阅/数据库/界面
       └─ 独立APK RootService（UID0）：身份检查、策略发布、受限特权接口
```

目标进程不运行第二套规则，不接收任意Shell规则。Root协议版本7；节点策略根据真实socket对端UID和已安装包判断，不信任客户端自报包名。仅user0／999常规单包身份参与；系统UID、隔离或共享UID等不明确身份保持拒绝。Root服务就绪后发布`GKDGLOBAL1`保护包缓存，首次未知策略不放行。

全局助手仅管理本桥接取得的节点连接。退出前台、关闭功能、策略撤销、Root失联或租约到期时撤回；连接/清理失败应被隔离，不改变宿主应用原操作。主线程不阻塞等待策略IPC；定时清理不被阻塞的IPC线程拖住。宿主私有API不兼容时不保证节点可用。

## 黑白名单、双开与HMA

- 名单在主用户GKD中管理，主/双开共享策略；加入白名单对已连接目标撤销，移出可在同进程恢复。节点可用不代表某条规则一定命中，`ActionSubmitted`也不代表点击已验证。
- 含指定检测器的启动器文件夹内应用由既有检测文件夹逻辑列为保护对象；此逻辑依赖实际目录数据可读，不能据此承诺任意启动器/所有ROM。
- 正常全局路线不需要开启GKD的LSPosed模块或逐项勾选作用域，不需要GKD999登记。旧LSP兼容入口仍可存在，但不作为全局功能的前置条件。
- HMA预设保持原样，不伪造应用看到的无障碍开关/服务清单。识别仍依赖可用节点而非截图/OCR；绘制在不可访问表面上的内容没有必然可读保证。

## 首装、升级与保活

模块安装器为主用户执行`pm install --user 0 -r`。仅在内外存均无既有设置时写`module_bootstrap_v1`并初始化相应权限/无障碍；保留其他服务。应用本身首次Root必须由用户在管理器批准，不把Root宿主已工作等同于APK已获授权。

Root获取异步执行；非Root缓存Shell关闭后再重试。只有owner模块首次引导且未完成时，最多20次、15秒间隔、5分钟窗口等待；确认Root身份后写`module_root_ready_v1`。关闭开关停止等待。服务握手的超时不吞并用户授权时间，也不无限弹授权。

已有配置升级不重写开关和规则。新默认Root＋无障碍路线不要求Shizuku；原配置使用Shizuku者保留其授权。不要为了普通升级卸载APK，UID变化会使外部授权失效。

模块等待开机及系统服务，解锁后应用数据可读再就绪；启动退避并确认稳定后低频巡检，默认300秒检查、1800秒刷新后台策略。用户关闭状态通知时不强行恢复其关闭偏好。卸载模块只清本模块保活/登记/生成缓存，不卸载APK、不清数据/规则或既有999登记；已加载Native卸载/替换通常需要重启。

## 窗口恢复与动作真实性

聚焦、可见、运行中的前台任务可能先于窗口节点挂载。缺窗口只允许有界重采样，不使未知窗口获得执行资格；PiP、错误身份与不明确前台继续拦截。动作前复核上下文，明确失败才按执行器契约降级；不确定已产生副作用时不重复提交。

节点来源、动作后端与策略是不同层次；本版实测使用`clickNode`并结合目标处理器标记及`ActionSucceeded state=Verified`，不是以进程存在/节点数量/已提交点击当作完整成功。

## 构建、分发与变更验收

默认模块12条目：APK、DEX、arm64/x86_64 SO及安装/保活/卸载脚本等；APK与独立产物字节相同，脚本LF、无BOM。32位需同时显式构建和打包，不在本次默认支持承诺。

`AppDistribution`使代码/反馈/分享/更新指向fork，禁用上游普通APK自动替换；在线规则更新保持独立。本地-2和在线667各保留ID，已存在文件/元数据及用户后来删除优先，不合并到同一ID。

变更Root协议、Java/Native租约、名单传播、首装或动作链需专项回归。Native换字节则追加重启对照；本次2.0仅沿用已实测v99相同Native，没有另做新重启。保留签名、配置、哈希、可执行回退及验证输出；私人备份不进入公开附件。原历史单APK计划的禁止Hook范围已被后续需求替代，其有限恢复与数据兼容原则仍有效。
